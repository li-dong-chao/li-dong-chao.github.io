基于MNIST数据集训练手写数字识别系统

15 Mar 2024

MNIST 是一个免费的开源数据集，由 70000 张 $28 \times 28$ 像素的黑白图片构成，其 60000 张为训练样本，10000张为测试样本。该数据集可用于训练手写数字识别模型，通常作为机器学习、深度学习的入门数据集使用。

本文尝试使用 pytorch 搭建一个简单的神经网络模型，并在 MNIST 数据集上进行训练，最终实现手写数字的识别。

本文主要介绍如何用 pytorch 实现整个流程，至于理论和最终的效果表现不是文本的重点。

数据获取与数据加载

torchvision 中集成了 MNIST 数据集，可以直接使用该框架来获取数据，获取数据的python代码如下：

 1from torch.utils.data import DataLoader
 2from torchvision.datasets import MNIST
 3from torchvision import transforms
 4from torch.utils.tensorboard import SummaryWriter
 5
 6# 获取训练集数据
 7train_data = MNIST(root='../data', train=True, download=True, transform=transforms.ToTensor())
 8# 获取测试集数据
 9test_data = MNIST(root='../data', train=False, download=True, transform=transforms.ToTensor())
10
11# 使用dataloader进行数据加载
12data_loader = DataLoader(train_data, batch_size=64, shuffle=True)
13
14# 使用tensorboard实现图片数据展示
15with SummaryWriter(log_dir='../logs') as writer:
16    for i, (imgs, targets) in enumerate(data_loader):
17        writer.add_images("train", imgs, i)

执行上面的代码，程序将会自动下载 MNIST 数据集。在 MNIST 的各个参数中， root 参数表示数据的存储路径，下载的数据将会保存至该目录下；train 参数表示是否下载训练集，当取值为 True 时，程序会下载训练集数据，否则下载测试集数据；download 参数表示是否自动下载数据集，当 root 目录下不存在数据时，程序会自动从互联网下载数据；transform 参数表示要对数据进行的后处理，这里的 transforms.ToTensor() 表示将数据转化为 tensor 对象。

上面代码中，除了获取数据还构造了一个 dataloader ，用于实现对训练集（或测试集）数据的批次取样，上面代码中的 batch_size=64 表示数据将以每批64张图片的形式进行取样，shuffle=True 则表示在取样前会对数据进行随机打乱。

代码的最后三行主要作用是利用 tensorboard 实现图片数据的可视化展示，其中 log_dir 指定了 tensorboard 缓存数据的目录，writer.add_images 方法则会添加数据到 tensorboard 的数据展示面板。执行完上述代码后，在命令行窗口执行 tensorboard --logdir="../logs" 便能够启动数据展示面板，形式如下。通过该面板，可以对数据集进行初步的查看。

创建神经网络模型

使用 pytorch 框架可以很方便的创建机器学习模型，其 nn 模块内置了神经网络、深度学习常用的多种连接层，具体包含哪些连接层，可以从 pytorch 官网 查看。除了各种连接层外，nn 模块提供的 Sequential 方法还支持将多个连接层连接到一起，创建一个网络结构。

本文基于 nn 模块创建了一个简单的神经网络模型，它由3个线性层、2个 ReLU 激活层以及1个 softmax 层构成，该网络结构的构建代码如下：

 1from torch import nn
 2
 3
 4class MyNetwork(nn.Module):  # 从 nn.Module 继承，创建一个模型
 5    def __init__(self):
 6        super().__init__()
 7        self.model = nn.Sequential(  # model属性记录模型的结构，具体哪些结构可以直接从 nn 模块获取，这里只是随便搭建了一个网络
 8            nn.Flatten(),
 9            nn.Linear(28 * 28, 64),
10            nn.ReLU(),
11            nn.Linear(64, 32),
12            nn.ReLU(),
13            nn.Linear(32, 10),
14            nn.Softmax(dim=1)  # 由于数据标签为多分类，模型最后使用 softmax 实现多分类
15        )
16
17    def forward(self, x):
18        output = self.model(x)
19        return output

上面的网络结构中，由于 MNIST 数据集中图片大小为 $28 \times 28$，所以第一个线性层的输入元素参数必须为 28*28；由于手写数字识别的标签为 0-9 共10个数字，所以最后一个线性层的输出元素参数必须为 10 。除此之外，所有线性层参数均为超参数，可以根据模型表现进行相应的调整。

本文只是为了梳理整体训练流程，上面的结构只是随便构建的，其结构及参数情况可能并不是最优的。事实上，使用简单的神经网络来实现手写数字识别，效果相比于深度学习中 CNN 等网络结构要差许多，如果读者比较关注最终的效果表现，请尝试使用其他的网络结构。

结合 tensorboard 工具，可以对网络结构进行可视化，代码如下：

训练模型

下面介绍如何基于 pytorch 实现网络的训练。

损失函数

手写数字识别是一个典型的多分类任务，针对多分类任务，经常会采用 交叉损失函数 来作为损失函数。在 pytorch 中可以使用 CrossEntropyLoss 来实现交叉损失函数的计算。

1from torch.nn import CrossEntropyLoss
2
3# 构建交叉熵损失计算器
4loss_fn = CrossEntropyLoss()

优化方法

确定损失的计算方式后，还需要进一步确定使用何种最优化方案来实现损失最小化，或者说实现对模型参数的优化。本文直接使用 梯度下降法 作为最优解的求解方法。在 pytorch 中创建最优化迭代器的代码如下：

1from torch.optim import SGD
2
3# 学习率
4learning_rate = 0.005
5# 创建最优化迭代器
6optimizer = SGD(model.parameters(), lr=learning_rate)
7# 这里的model为自己定义网络结构类后，实例化的对象，对应上面构建网络的代码，即为 model = MyNetwork()

将上面的代码进行整合，便能够得到最终的训练代码。

 1#!/usr/bin/env python
 2# -*- encoding: utf-8 -*-
 3import torch
 4import torchvision
 5from torch.nn import CrossEntropyLoss
 6from torch.optim import SGD
 7from torch.nn.functional import one_hot
 8from torch.utils.data import DataLoader
 9from torch.utils.tensorboard import SummaryWriter
10
11from app.model.network import MyNetwork
12
13# 加载数据
14train_data = torchvision.datasets.MNIST(
15    root='../data',
16    train=True,
17    download=True,
18    transform=torchvision.transforms.ToTensor(),
19)
20test_data = torchvision.datasets.MNIST(
21    root='../data',
22    train=False,
23    download=True,
24    transform=torchvision.transforms.ToTensor()
25)
26
27train_size = len(train_data)
28test_size = len(test_data)
29
30train_dataloader = DataLoader(train_data, batch_size=64)
31test_dataloader = DataLoader(test_data, batch_size=64)
32
33# 使用tensorboard来记录训练过程
34writer = SummaryWriter('../log')
35
36total_train_step = 0
37epoch = 100
38learning_rate = 0.005
39
40model = MyNetwork()
41# 创建优化器
42optimizer = SGD(model.parameters(), lr=learning_rate)
43# 创建损失
44loss_fn = CrossEntropyLoss()
45
46# 开始训练
47for i in range(1, epoch + 1):
48    print(f"第 {i} 轮训练开始".center(20, "-"))
49
50    # 开始训练
51    total_loss = 0
52    model.train()
53    for data in train_dataloader:
54        imgs, targets = data
55        targets = one_hot(targets, 10).float()
56        output = model(imgs)
57        loss = loss_fn(output, targets)
58
59        # 反向传播
60        optimizer.zero_grad()
61        loss.backward()
62        optimizer.step()
63
64        total_train_step += 1
65        total_loss += loss.item()
66
67        if total_train_step % 100 == 0:
68            print(f"训练次数：{total_train_step}，Loss：{loss.item()}")
69        writer.add_scalar("total_train_step vs train_loss", loss.item(), total_train_step)
70
71    writer.add_scalar("epoch vs train_loss", total_loss, i)
72
73    # 测试
74    model.eval()
75    total_right_num = 0
76    with torch.no_grad():
77        for data in test_dataloader:
78            imgs, targets = data
79            output = model(imgs)
80            right_num = sum(output.argmax(1) == targets)
81            total_right_num += right_num
82    test_accuracy = total_right_num / test_size
83    print(f"测试集准确率：{test_accuracy}")
84    writer.add_scalar("epoch vs test_loss", test_accuracy, i)
85
86# 保存模型
87torch.save(model.state_dict(), "../model/model.pth")
88
89writer.close()
